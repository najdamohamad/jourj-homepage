# Jour J — production site (`web/`)

Next.js App Router rebuild of the design handoff in `../source/` (marketing homepage).

## Run locally

```bash
cd web
npm install   # once
npm run dev
```

Then open http://localhost:3000 .

## Assets

PNG product photos listed in **`public/assets/README.md`** are referenced by path but **not included** in this download. Copy them from the design archive into `public/assets/` keeping the filenames from the root `README.md` (section 9, « Imagery ») so imagery appears.

SVG brand assets shipped: `jour_j_calendar_icon.svg`, `jour_j_wordmark.svg`.
